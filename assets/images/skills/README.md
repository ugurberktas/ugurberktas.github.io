# Skill icon sources

- Brand SVGs, except Rootly, come from [Simple Icons](https://simpleicons.org/) through its CDN and are used in the site's orange accent color. Simple Icons is a CC0 project; individual brands may publish their own usage guidelines.
- The Rootly glyph comes from Rootly's official [brand page](https://rootly.com/brand).
- CI/CD, AWS, SQL Server, and REST API use the Font Awesome icon set already loaded by the site. Generic concepts use representative symbols rather than claiming an official logo.
